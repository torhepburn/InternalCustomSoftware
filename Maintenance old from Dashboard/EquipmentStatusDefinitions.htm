Dashboard Maintenance - Equipment Status Descriptions
Up - System fully operational.

Down - System not operational and not being worked on.

Limited Use - System partially operational.

Unscheduled Maint - Unscheduled maintenance is being performed.

Preventive Maint. - Scheduled maintenance is being performed.

Parts - System waiting for parts, and the parts have been ordered.

Engineering - System under engineering control not released to production.

Facilities - Utilities problem causing system to not be operational.

Install - System being initially installed in building or moved.

Software Feature - Additional feature to software.

Software Bug Fix - Known bug in system has been fixed.
